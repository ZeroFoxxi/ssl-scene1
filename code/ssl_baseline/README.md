# ssl_baseline：场景一基线 B0（摄像头声源定位与持续跟踪）

调研方案中“基线 B0”的可运行雏形：**L0 常开触发 → SRP-PHAT 测向（起始段加权）→ 圆周卡尔曼跟踪（6 中取 3 起始）→ 云台状态机（死区 / 电机门控 / 干扰方向表）**，并配有房间声学仿真、评测指标、单元测试和三个演示脚本。

> 定位：调研阶段用于验证方案逻辑、给出量化依据的原型，不是产品代码。所有结果都来自镜像源法仿真，视觉检测为模拟，需在真实数据和设备上复核。

## 当前结果（仿真，2026-11-07）

**静态测向**（100 个随机房间，1 s 中文语音，传感器噪声 SNR 15 dB，4 麦方阵孔径 5.7 cm）

| RT60 | SRP-PHAT MAE / Acc@10° / 粗大错误 | + 起始段加权 |
|---|---|---|
| 0.2 s | 2.6° / 99% / 0% | 2.4° / 99% / 0% |
| 0.4 s | 5.6° / 88% / 0% | 5.0° / 89% / 0% |
| 0.6 s | 9.2° / 64% / 0% | 7.6° / 69% / 0% |
| 0.8 s | 12.9° / 54% / 4% | 8.5° / 69% / 1% |

2 麦线阵因前后镜像，粗大错误约 45–65%；3 麦与 4 麦单声源精度接近（见 `out/static_eval.csv`）。

**闭环演示**（RT60 0.5 s，说话人从画面外开口并绕行 170°，HFOV 90°）

- 从触发到开始转动 0.29 s，到目标入画 0.67 s
- 入画后目标 100% 在画面内、98.8% 在画面中央一半；17 s 内云台移动 10 次
- 融合（模拟）视觉后跟踪平均误差 1.3°

**电视干扰演示**（电视在画面内持续放人声且无人，真人 12 s 后在画面外开口）

- 不启用干扰方向表：跟踪器锁定电视，始终未转向真人
- 启用：电视方向（310–330°）在“有声无人”4 s 后被屏蔽，示例中真人开口 3.02 s 后首次入画
- 8 个随机种子（`python scripts/run_tv_interference_demo.py --seeds 8`）：启用 7/8 转向真人（5 次 ≤ 3.1 s、2 次 11–13 s、1 次未转向），不启用 0/8

## 唤醒词定向接口（2026-11-10）

```python
from ssl_baseline.wake import WakeWordLocalizer, localize_wake_segment

loc = WakeWordLocalizer(mic_xy, fs=16000)        # 内含 3 s 多通道环形缓存
loc.push(block)                                  # 每块 M x n 音频推入
res = loc.on_wake(start_sample, end_sample)      # 唤醒回调：唤醒词起止（自开机以来的绝对样点号）
res.az, res.conf, res.candidates                 # 方位（°）、置信度 [0, 1]、候选方位
```

方法：片段两端各放宽 0.1 s → 起始段加权估计唤醒词协方差 R_s → 用唤醒词前 1 s 背景估计 R_b → R_b 白化后做 MUSIC（GEVD-MUSIC）。电视等唤醒前就存在的定向干扰被白化掉。`WakeDOAConfig(method="srp_sub")` 为背景互谱扣除 + SRP-PHAT 的备选；`exclude` 可传入云台的干扰方向表。

结果（仿真，每档 RT60 100 个随机房间，1 s 唤醒词，电视与人相隔 ≥45°，传感器 SNR 20 dB；误差 ≤10° 比例 / 粗大错误）：

| RT60 | 条件 | SRP-PHAT + 起始段加权（原基线） | + 背景互谱扣除 | **GEVD-MUSIC（默认）** | 不用背景段的 MUSIC |
|---|---|---|---|---|---|
| 0.3 s | 电视关 | 94% / 0% | 91% / 0% | 91% / 0% | 91% / 0% |
| 0.3 s | 电视 SIR 0 dB | 36% / 28% | 46% / 17% | **74% / 2%** | 37% / 45% |
| 0.6 s | 电视关 | 88% / 0% | 79% / 0% | 88% / 0% | 86% / 0% |
| 0.6 s | 电视 SIR +5 dB | 55% / 10% | 48% / 10% | **71% / 2%** | 60% / 16% |
| 0.6 s | 电视 SIR 0 dB | 35% / 25% | 34% / 21% | **63% / 3%** | 36% / 39% |
| 0.6 s | 电视 SIR −5 dB | 20% / 40% | 18% / 41% | **55% / 8%** | 13% / 60% |

- KWS 起止点误差 σ = 0.1 s：影响在统计波动范围内。
- 置信度按三等分：≤10° 比例 54% / 75% / 93%，可用于决定“直接转”还是“等更多观测”。
- 单次测向 Python 约 6 ms。
- 局限：要求唤醒前背景段里用户本人不说话；电视与人方位接近（<45°）的情况未评测。

## 关键设计与参数

| 模块 | 参数 | 默认值 | 说明 |
|---|---|---|---|
| SRP-PHAT | 频带 | 300–4000 Hz | 上限不超过空间混叠频率（4 麦相邻间距 4 cm 约 4.3 kHz） |
| SRP-PHAT | 置信度 | 归一化峰值（空间相干度） | 理想平面波为 1，混响 / 多源时下降；门限 0.2 |
| 起始段加权 | 帧权重 | 0.2 + 能量上升量 / 10 dB | 利用优先效应：起始段以直达声为主 |
| 跟踪器 | 起始 | 6 中取 3，±10° | 比“连续 3 帧一致”更抗野值 |
| 跟踪器 | 门控 / 保持 | ±30° / 3 s | 静音期保持航迹 |
| 状态机 | 死区 | ±15°（HFOV 90°） | 目标偏离中心小于此值不转 |
| 状态机 | 电机门控 | 转动期间冻结声学观测 | 电机噪声会把测向拉向电机方向 |
| 状态机 | 干扰方向表 | 画面内跟踪目标“有声无人”4 s（演示值）→ 屏蔽 ±10° | 看到真人自动解除 |

## 已知局限与下一步

1. 仿真未包含家具散射、真实噪声、麦克风失配；需用 RealMAN 子阵、LOCATA 与设备实录复核。
2. 视觉检测为模拟；接入真实人形检测 / Light-ASD 后复测。
3. 单块（100 ms）测向在强混响下仍有约 25% 粗大错误，靠跟踪器兜底；主方案 M1（轻量 SELD 网络）的目标是提升单块精度、缩短确认时间。
4. 多声源只做了单目标跟踪；多人场景需 GM-PHD 或多假设跟踪。
5. 需要按目标芯片评估实时性（SRP-PHAT 4 麦 6 对 × 119 频点 × 360 方向 / 帧，可降为 5° 网格或分层搜索）。

## 实现中踩过的坑

- **TTS / 录音的直流偏置**：经过混响房间后被 RIR 的直流增益放大，虚高总功率；若按总功率设定噪声，实际带内信噪比会远低于标称值，测向结果被严重低估。所有仿真信号先高通（100 Hz）去直流。
- **L0 噪声底初始化**：若一开机就有持续声源（电视），噪声底会被初始化到电视电平，电视永远不触发；演示中让电视 2 s 后开始播放。产品中需用最小值统计等更稳健的噪声底估计。
- **置信度定义**：(峰值 − 均值) / 标准差 对小孔径阵列的宽主瓣不敏感；改用归一化 SRP 峰值（空间相干度）。
