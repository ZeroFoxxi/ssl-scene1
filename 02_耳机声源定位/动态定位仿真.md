# 动态定位仿真：说话人移动、佩戴者转头、干扰有停顿

> 2026-11-18。对应 mentor 11-17 的后续工作"说话人移动场景下的动态定位与持续跟踪"，以及方案中的"转头跟住""干扰有停顿时声学能否检测开口"。
> 代码：`code/earbud_ssl/scripts/run_motion.py`、`run_onset_pauses.py`；结果：`out/motion_moving.json`、`out/motion_turn.json`、`out/onset_pauses.json`。
> 数字均为【仿真】（刚性球头部模型，无耳廓；混响为扩散场近似）；解读标【判断】。

## 1. 结论

- **说话人慢速移动（≤ 20°/s）能跟住**：跟踪 + 视觉在干扰低 6 dB 时 85–92%，干扰一样响时 73–84%（每 0.25 s 一次输出、误差 ≤ 10° 的比例）。
- **快速移动（40°/s，约相当于 1.5 m 外的人正常走过）是弱点**：跟踪 + 视觉降到 69 / 53%，比只用最近 0.25 s 测向（77 / 67%）还差——跟踪器跟不上，正确的观测被门限挡掉。12 月改进：以摄像头 10–15 fps 的人脸跟踪为主，声学做确认【判断】。
- **转头要 IMU + 视觉一起才能跟住**：转头 30° 时 87 / 77%，60° 时 77 / 67%；只用 IMU（背景协方差按转角旋转、输出换算）比不用 IMU 的跟踪高 4–12 个百分点，但与不用 IMU 的逐窗测向相当（−1 到 +2）。
- **干扰有停顿也不能只靠声学检测开口**：干扰说一段停一段、或轮流说话时，检出与误报仍无法兼顾（干扰重新开口同样触发）。"对话中摄像头保持唇动档"的设计结论不变（11-21 摄像头策略仿真后，方案改为默认只开监测档、唇动档视功耗常开，见 `摄像头使用策略.md`；只靠声学检测开口不可靠这一点仍成立）。

## 2. 设置

| 项目 | 设置 |
|---|---|
| 阵列与方法 | 主耳 2 + 副耳 1 路；GEVD-MUSIC，5° 网格；背景为目标开口前的一段 |
| 声学环境 | 混响 RT60 0.5 s；2 个固定干扰说话人全程说话（S2：各低 6 dB；S4：一样响）；扩散噪声 SNR 10 dB |
| 时间轴 | 目标前 1 s 不说话，1–6 s 一直说；从 1.5 s 起每 0.25 s 输出一次头部坐标方位 |
| 移动 | 目标从 ±30° 内出发，以 0 / 10 / 20 / 40 °/s 绕佩戴者移动（限制在 ±80° 内），头不动 |
| 转头 | 目标与干扰不动，佩戴者在 3.0–3.5 s 内转头 0° / 30° / 60°；IMU 读数加 0.5° 噪声 |
| 跟踪 | 场景一的圆周卡尔曼（方位 + 角速度），块长 0.25 s；参数在开发种子 999 上从 4 组中选定（q_az 4、q_vel 100、门限 45°），评测种子 51 |
| 视觉 | 视野 ±70°，检出 95%，方位误差 2°，唇动错误 10%；每 0.25 s 与空间谱软融合一次 |
| 次数 | 每档 60 次 |

逐帧按当时的头部坐标方位取直达声传递函数（1° 表），实现方向随时间变化；混响尾为扩散场近似，与方向无关。

## 3. 说话人移动（误差 ≤ 10° 的比例，干扰低 6 dB / 一样响）

| 速度 | 逐窗 0.5 s | 逐窗 0.25 s | 跟踪 | 跟踪 + 视觉 |
|---|---|---|---|---|
| 0°/s | 84 / 73% | 77 / 67% | 88 / 80% | 89 / 79% |
| 10°/s | 83 / 72% | 76 / 65% | 90 / 77% | **92 / 84%** |
| 20°/s | 83 / 70% | 75 / 67% | 80 / 55% | **85 / 73%** |
| 40°/s | 70 / 61% | **77 / 67%** | 60 / 47% | 69 / 53% |

- 不动时（0°/s）连续输出约 84–89% / 73–80%，低于单次判决的 95% / 89%：连续 4.5 s 的输出里包含目标停顿、干扰盖过目标的时段。
- 窗长的取舍：0.5 s 窗更稳，但快速移动时方向被"抹开"；0.25 s 窗在 40°/s 时更好。

## 4. 转头（误差 ≤ 10° 的比例，干扰低 6 dB / 一样响）

| 转头 | 不用 IMU（逐窗） | 不用 IMU（跟踪） | 只用 IMU（跟踪） | IMU + 视觉（跟踪） |
|---|---|---|---|---|
| 0° | 84 / 73% | 88 / 80% | 88 / 78% | 89 / 79% |
| 30° | 72 / 55% | 67 / 49% | 74 / 54% | **87 / 77%** |
| 60° | 66 / 48% | 63 / 37% | 67 / 49% | **77 / 67%** |

转头期间（3.0–3.75 s）与转头之后（3.75 s 以后）分开看，IMU + 视觉：30° 时 76 / 72%、93 / 78%；60° 时 60 / 59%、76 / 61%。

- 只用 IMU 帮助小的原因【判断】：开口前估计的背景协方差在转头后不再对应干扰的实际方向；按转角旋转背景（从背景中估出干扰方向再平移）是近似，旋转误差会削弱白化。
- 视觉在转头时帮助大：人脸方位直接给出目标在头部坐标中的位置，不依赖旧背景。

## 5. 干扰有停顿时的声学开口检测（阈值 3.0 dB，干扰低 6 dB / 一样响）

| 干扰说话方式 | 检出率 | 每分钟误报 | 唇动给开口时刻时的测向（加视觉） |
|---|---|---|---|
| 一直说话 | 43 / 21% | 6 / 12 次 | 93 / 89% |
| 说 1–3 s、停 0.3–1.5 s | 54 / 38% | 11 / 19 次 | 98 / 88% |
| 轮流说话（上一个人停下 0.1–0.5 s 后目标开口） | 46 / 20% | 9 / 17 次 | 99 / 99% |

- 有停顿时检出略升，但误报也升：干扰每次重新开口都像"新声源"。
- 轮流说话时，只要开口时刻由唇动给出，测向几乎全对（目标说话时没人插话）。

## 6. 对方案的影响

| 方案中的说法 | 现在的依据 | 改动 |
|---|---|---|
| 说话人移动：地图中每人改为方位 + 角速度跟踪 | 慢速移动有效；快速移动反而变差 | 增加：快速移动以人脸跟踪为主，声学确认；跟踪器按速度自适应【12 月】 |
| 转头跟住（IMU） | 只用 IMU 帮助小，IMU + 视觉有效 | "转头跟住"依赖视觉；视觉不可用时转头后需要重新估计背景 |
| 对话中摄像头保持唇动档 | 干扰有停顿时声学检测也不可靠 | 当时结论不变；11-21 按摄像头策略仿真改为两种工作方式 |

## 7. 局限

- 刚性球头部模型，无耳廓；混响尾与方向无关的扩散近似。
- 背景只用开口前的一段，没有在目标停顿时递推更新；加上唇动门控递推后，转头、移动时的结果可能更好【12 月】。
- 跟踪器只在 4 组参数中选择，没有做速度自适应；视觉每 0.25 s 融合一次，没有用到 10–15 fps 的人脸轨迹。
- 每档 60 次，统计误差约 ±5–6 个百分点。
