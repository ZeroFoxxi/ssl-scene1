# 耳间转发的 1 路音频怎么编码：对测向的影响【仿真】

> 2026-11-23。回答方案中待验证的一项："副耳转发给主耳的 1 路音频能否用 ADPCM 压缩、LC3 这类感知编码能否用于定位"。
> 代码：`code/earbud_ssl/scripts/run_codec.py`；结果：`out/codec.json`（汇总）、`out/codec_trials.json`（逐段）。
> 更正：同日第一版结果中感知编码"低 3–7.5 个百分点、不用于定位"不成立。原因是脚本逆变换时信号首尾两端被放大成尖峰（峰值超过满量程、被削波），并带偏了电平归一化；修正后重跑，结果见下。

## 1. 结论

1. **三种压缩编码与 PCM 相比都没有显著损失**【仿真，每个条件 200 段】：IMA ADPCM 4 bit、G.722、Opus 32 kbps（代替 LC3）的准确率与 PCM 相差都在 2.5 个百分点以内，逐段配对的符号检验 p 均 ≥ 0.22。
2. **定位转发默认用 IMA ADPCM 4 bit（64 kbps）**【判断】：
   - 加视觉时 94.0% / 77.0%，PCM 为 93.5% / 79.0%；纯声学 86.0% / 61.5%，PCM 为 87.0% / 63.0%。
   - 链路每侧约 0.7 mW，比 PCM（2.6 mW）约省 1.9 mW【估算】，续航多约 0.2 h；没有编解码帧时延，实现简单。
3. **感知编码（LC3 类）不必排除**：用 Opus 32 kbps 测试时准确率没有显著下降，但估计方位的细小抖动更大（与 PCM 相差不到 2° 的段，纯声学、干扰一样响时 77%，ADPCM 为 86%），且有约 10 ms 级的帧时延。如果耳间链路只支持 LC3，可以用，但需用 LC3 本身复核【待确认】。

## 2. 设置

| 项目 | 设置 |
|---|---|
| 场景 | 与算法选型 S2、S4 相同：混响 RT60 0.5 s、2 个干扰说话人（各低 6 dB / 与目标一样响）、扩散噪声 SNR 10 dB；目标在前方 ±60°、1–2 m；每个条件 200 段，各编码用同一批场景 |
| 阵列 | 2+1：主耳 2 路 + 副耳转发 1 路（右前麦） |
| 信号链 | STFT 域仿真 → 逆变换回时域 → 三路统一按 16 bit 量化（副耳那一路中间段均方根 −30 dBFS）→ 只对副耳那一路编码再解码 → 测向 |
| 编码（ffmpeg） | PCM 16 bit（参照）；IMA ADPCM 4 bit；G.722 64 kbps；Opus 32 kbps（10 ms 帧，代替 LC3） |
| 编码时延 | 白噪声探测后按整数样点补偿（G.722 22 个样点，其余 0），实际系统中该时延已知 |
| 测向 | GEVD-MUSIC（唇动门控背景，起始段加权，5° 网格），开口后 0.5 s 判决；加视觉为软融合（λ = 0.1、μ = 0.05、±8°），视觉按假设模拟 |

## 3. 结果（方位误差 ≤ 10° 的比例，每个条件 200 段）

| 编码 | 码率 | 编码误差信噪比（中位数） | 干扰低 6 dB：纯声学 / 加视觉 | 干扰一样响：纯声学 / 加视觉 |
|---|---|---|---|---|
| PCM 16 bit | 256 kbps | 71 dB | 87.0% / 93.5% | 63.0% / 79.0% |
| IMA ADPCM 4 bit | 64 kbps | 25 dB | 86.0% / 94.0% | 61.5% / 77.0% |
| G.722 | 64 kbps | 28 dB | 87.0% / 93.5% | 63.0% / 78.5% |
| Opus（代替 LC3） | 32 kbps | 17 dB | 85.5% / 93.0% | 62.5% / 76.5% |

与 PCM 逐段配对：对 → 错 / 错 → 对 的段数（符号检验 p），以及估计方位与 PCM 相差不到 2° 的段所占比例：

| 编码 | 干扰低 6 dB：纯声学 | 加视觉 | 干扰一样响：纯声学 | 加视觉 |
|---|---|---|---|---|
| IMA ADPCM | 2 / 0（p = 0.50），94.5% | 0 / 1（p = 1），98.5% | 5 / 2（p = 0.45），86.0% | 5 / 1（p = 0.22），93.5% |
| G.722 | 1 / 1（p = 1），96.5% | 0 / 0，99.0% | 8 / 8（p = 1），82.0% | 5 / 4（p = 1），93.5% |
| Opus | 5 / 2（p = 0.45），89.5% | 2 / 1（p = 1），97.5% | 9 / 8（p = 1），77.0% | 11 / 6（p = 0.33），89.5% |

PCM 参照（93.5% / 79.0%）与麦克风数量仿真中 2+1 的结果（96% / 80%，100 段）在统计误差内一致。

## 4. 局限

- LC3 在当前环境无法安装，用同为感知编码的 Opus 代替；两者算法不同，LC3 的实际影响需要用 LC3 复核。
- 仿真中的扩散混响和噪声是逐帧独立生成的，逆变换回时域后再变换，与原来的频谱并不完全一致；各编码用同一个时域信号配对比较，PCM 参照与原结果一致，比较本身成立。
- 刚性球头部模型；12 月用实测头部传递函数复核（`12月仿真计划.md`）。
- 只编码了副耳那一路；两耳链路的丢包、重传未建模。
