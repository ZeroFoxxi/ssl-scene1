# 耳机声源定位 demo

## 目标

mentor 负责的耳机 demo：耳机上加摄像头，目标是实现**声源定位 + 音效渲染**；本人可以参与。

- 先侧重音频：通过耳机上的麦克风做声源定位；摄像头（视觉）后续作为校正手段。
- 需要先回答的问题：**选定的场景下，为什么必须佩戴耳机？**（以及：为什么摄像头要放在耳机上，而不是手机或眼镜上。）

## 初步思路（判断，待与 mentor 确认）

- 耳机独有的三点：声音最终要送进耳朵；降噪耳机把人与环境隔开，需要设备补回方向信息；麦克风随头转动、位于耳朵处，方向天然是头部坐标。
- 候选场景：嘈杂环境听清对面的人；降噪时的环境感知（有人叫你、身后来车）；空间音频渲染。
- 纯音频测向的难点：两耳相距约一个头宽、左右准但前后易混；每只耳机麦克风间距仅一两厘米；头部持续转动需用 IMU 换算到世界坐标；两耳互传音频还是只传参数；佩戴者自身语音干扰；实时链路时延。
