# 方向模板与真实头部不一致时，定位掉多少【仿真】

> 2026-11-23。回答"头部传递函数（头型、佩戴）不准会不会影响方案"。
> 代码：`code/earbud_ssl/scripts/run_mismatch.py`；结果：`out/mismatch.json`、`out/mismatch_log.txt`。

## 1. 结论

1. **加视觉时基本不受影响**【仿真】：各种不一致下，方位误差 ≤ 10° 的比例为 94–95% / 80–85%（干扰低 6 dB / 一样响），模板一致时为 95% / 83%；最不利的"综合"低 1 / 3 个百分点。
2. **只靠声学时，头型不一致影响最大**【仿真】：
   - 误差 ≤ 10° 的比例变化不大（81.5–90.5% 对 88.5%）；
   - 但误差 ≤ 5° 的比例从 86.5% 掉到 47.5–56.5%（干扰一样响时从 63.5% 掉到 35.5–39%），即出现约 5–10° 的系统偏差：头比模板大或小，两耳时间差随之变大或变小，测出的方位被整体"拉宽"或"压窄"。
   - 装配误差 2 mm、佩戴上下倾 ±20°、左右偏 ±10° 的影响都在统计误差内。
3. **对方案的影响**【判断】：
   - 不改变方案。方向模板按标准头型做一次即可。
   - 头型带来的系统偏差可以用方案已有的在线校正消除：视野里只有一个人说话时，比较人脸方位与声学方位，校正声学方位的比例（`整体设计方案.md` 8.3）。这对暗光等只能靠声学的情况有用。
   - 刚性球没有耳廓，耳廓的影响不在此列，仍需实测头部传递函数复核（`12月仿真计划.md`）。

## 2. 设置

| 项目 | 设置 |
|---|---|
| 场景 | 与算法选型 S2、S4 相同（见 `仿真场景说明.md`）：目标在正前方 ±60°，另有 2 个人一直在说（低 6 dB / 一样响），开口后 0.5 s 判决；每种情况 200 段，各情况用同一批声学场景 |
| 模板 | 刚性球，头半径 8.75 cm，标称麦克风位置（不变） |
| 真实头部 | 一致；头小（半径 7.5 cm）；头大（10 cm）；装配误差（每个麦克风每轴 σ = 2 mm）；佩戴角度（每只耳机绕耳轴随机 ±20°，前后两麦连线上下倾斜）；佩戴偏转（绕竖直轴随机 ±10°）；综合（头半径 7.5–10 cm 随机 + 以上三项） |
| 测向 | GEVD-MUSIC（唇动门控背景，起始段加权，5° 网格）；加视觉为软融合，视觉按假设模拟 |

## 3. 结果（每种情况 200 段）

方位误差 ≤ 10° / ≤ 5° 的比例：

| 真实头部 | 干扰低 6 dB：纯声学 | 加视觉 | 干扰一样响：纯声学 | 加视觉 |
|---|---|---|---|---|
| 一致 | 88.5% / 86.5% | 95.0% / 94.5% | 66.5% / 63.5% | 83.0% / 82.5% |
| 头小 7.5 cm | 90.5% / 56.5% | 94.0% / 90.5% | 63.0% / 39.0% | 85.0% / 82.0% |
| 头大 10 cm | 83.0% / 47.5% | 94.0% / 89.0% | 60.0% / 35.5% | 83.5% / 81.0% |
| 装配误差 2 mm | 86.0% / 83.5% | 94.0% / 93.0% | 65.0% / 63.0% | 83.0% / 82.5% |
| 佩戴角度 ±20° | 89.5% / 87.0% | 95.0% / 94.5% | 64.5% / 62.5% | 83.5% / 83.0% |
| 佩戴偏转 ±10° | 88.5% / 86.5% | 95.0% / 94.5% | 66.0% / 63.5% | 83.5% / 83.0% |
| 综合 | 81.5% / 67.0% | 94.0% / 93.0% | 62.5% / 52.5% | 80.0% / 79.5% |

200 段时比例的统计误差约 ±3–5 个百分点（95% 置信区间半宽，比例在 95% 到 85% 之间时）。

## 4. 局限

- 刚性球头部模型：耳廓、躯干、耳机外壳的遮挡未建模。
- 佩戴扰动在每段内固定；戴着说话时耳机慢慢移位未建模。
- 视觉按假设模拟，没有加入摄像头本身的佩戴偏差（人脸方位的换算误差）。
